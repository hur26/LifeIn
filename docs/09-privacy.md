# 09 · 隐私说明

**这份文档是给要接入的朋友看的,不是给开发者看的。**

它是 [03 的 P4 硬门槛](03-roadmap.md#前置硬门槛不满足则不开放)第 4 条:

> 写好隐私说明,明确告知朋友:你能看到什么、数据存在哪、如何删除

也是 [R10 那节改判](05-risks.md#r10--手机端采集器的越权读取)四个前提里的第 3 条 ——
而那一条要求的是**白纸黑字**,不是"心照不宣"。

---

## 0. 一句话

**这个系统跑在白杨自己租的一台服务器上,而白杨在技术上读得到你交给它的一切。**

下面所有内容都是这句话的展开。如果你读到这里就不想继续了,那是完全合理的反应,
**不接入不需要理由**。

---

## 1. 它会拿到你的什么

只有你**主动打开**的那几样。装了 App 不等于在采集 —— 通知使用权要你自己去
系统设置里开,白名单默认一条都不放行。

| 来源 | 拿到什么 | 怎么关 |
| --- | --- | --- |
| **手机通知与短信** | 你放进白名单的那些 App 的通知正文 | App 里关掉采集,或者收回系统的通知使用权 |
| **邮箱** | 你给的那个邮箱的邮件 | 删掉邮箱凭据 |
| **日历** | 企业微信的日程 | 不配企微就没有 |
| **副驾看到的对话** | 你开着副驾的时候,**当前那个聊天窗屏幕上的对话** | 收回系统的无障碍权限,或在 App 里关掉副驾 |

**验证码永远不会进来。** 手机端和服务端各过滤一次,命中即丢弃 ——
不入库、不记原文。这两道是**独立的**:一边改坏了另一边还在。

**你的群消息也会进来。** 白名单里放了微信,群里的消息就会被采到 ——
而**群里的其他人没有同意过这件事**。这一条你要自己想清楚:
你在替他们做一个他们不知道的决定。

### 关于副驾,要多说几句

副驾是 2026-09-22 加的新东西,**它看到的比上面那三样都多**,
所以单独讲清楚。

**它是什么:** 你在微信或 QQ 里聊天的时候,屏幕角上有一个小球。
点开它会告诉你对方大概想要什么,并给三条候选回复,点一下填进输入框。
**发送键永远是你自己按的** —— 它不会替你发,一次都不会。

**它看得到什么:** 只有你**此刻打开着的**那个聊天窗,屏幕上显示着的那些消息。
这里面包括通知采集拿不到的东西:

- 设了免打扰的群
- 长消息的完整内容(通知栏里会被截断)
- **你自己发出去的话**

最后那条要特别指出来:这是这个系统第一次会读到**你自己说了什么**。
通知采集永远读不到这个,因为自己发的消息不产生通知。
副驾需要它 —— 不知道你上一句说了什么,就判断不出对方这句是在回应什么。

**它看不到什么:**

- 别的聊天窗。它只认当前这一个
- 往上翻的历史。它读的是屏幕,屏幕上没有的它就没有
- **装它之前的聊天记录。永远拿不到**

**对话存在哪:** 存在**你自己的手机里**,每个会话最多 300 条,
不上传、不进服务器的数据库。App 里"清空副驾历史"一键删掉。
换手机或者重装 App,这些历史就没了 —— 这是有意的,没做备份。

**那什么东西会离开手机:** 分析那一次的请求。
屏幕上的对话会发给外部大模型让它读懂并起草回复,
**发完就完,服务器不留**。这一点和第 3 节里那条"事件的标题与正文"是同一类,
只是内容更长、更完整。

**群友的话在这里比别处更敏感。** 通知采集只拿得到通知栏展示过的那一条;
副驾拿得到你打开那个群时屏幕上的整段对话。虽然它不落库,
但**它确实在那一秒完整地经过了一次外部模型**。
如果你觉得这一条过不去,不要开副驾 —— 关掉它不影响日程、账单、记忆任何一样功能。

**默认是关的。** 无障碍权限和悬浮窗权限都要你自己去系统设置里开,
而且要逐个选哪些聊天 App 放行。装了 App 不等于副驾在工作,
开了通知采集也不等于。

## 2. 数据存在哪

- 一台**白杨租的云服务器**上的 PostgreSQL 里,不是任何一家网盘或第三方服务
- 邮箱授权码、设备密钥这类凭据是**加密存的**(字段级加密)
- 通知正文有**保留期**,过期自动清掉正文,只留结构化的字段
- **副驾的聊天记录不在这里。** 它存在你自己手机的本地数据库里,
  服务器上没有它的副本(见第 1 节那段)

## 3. 什么东西会离开这台服务器

**会离开的:**

| 去哪 | 什么 |
| --- | --- |
| 外部大模型接口 | 事件的**标题与正文**,用来做摘要、抽记忆、判断是不是一笔消费 |
| 外部大模型接口 | **副驾那一刻屏幕上的对话**,用来读懂对方并起草候选回复。**发完不留** |
| 微信 / 企业微信 | 推给你的那些消息本身 |
| 你自己的邮箱 | 兜底推送与月度报告 |
| **系统剪贴板** | 副驾填不进输入框时,那条候选会被放进剪贴板让你自己粘 |

**剪贴板那一行要单独说一句。** 它不去服务器,但它也不完全归这个项目管:
安卓 10 起只有当前在前台的 App 读得到剪贴板,可**输入法会把它记进
剪贴板历史**,而那份历史在输入法自己的地盘上。
只有填入失败时才会走到这一步(正常情况下文字直接进输入框,不经过剪贴板)。

**不会离开的:**

- 金额、卡号后四位这些字段**从不进模型** —— 它们由规则抠出来,直接入库
- 小票照片**不出手机**,识别在你自己的手机上做
- 凭据的明文任何时候都不出服务器
- **副驾的聊天记录不出手机。** 离开的是分析那一次的请求,不是那份历史 ——
  服务器读完就丢,不写进任何一张表
- **副驾截的屏不出手机。** 有些 App(比如飞书)的文字读不出来,
  这时它会截一张屏在**你手机上**认字,**图片本身不上传**

**关于外部模型那一条要说清楚:** 它是一家第三方公司的接口。
LifeIn 记录了每一次调用**送出去了哪些字段**(不是内容),
但**送出去之后的事情不在这个系统的控制范围内**。

## 4. 白杨能看到什么

**技术上:全部。**

这个系统的数据层强制按 `user_id` 隔离,那道隔离挡的是**代码走错**,
挡不住**有数据库权限的人**。白杨有那台服务器的 root,也有数据库密码。

所以准确的说法是:

- 代码不会把你的数据混进别人的账户里 —— 这一条有测试盯着
- **但白杨如果想看,他看得到,而且你不会知道**

**这一条不是可以商量的技术细节,是自托管这个形态的固有属性。**
任何说"你的数据只有你自己看得到"的自托管系统,要么在骗你,要么还没想清楚。

你能依靠的不是技术,是**你信不信白杨**。这份文档的作用是让你在
知道这件事的前提下做决定,而不是在不知道的前提下。

### 2026-09-10 起多了一个运营台,以及它留下的痕迹

白杨现在有一个要口令登录的网页后台,上面能看到跨所有人的运行状况:
谁的设备掉线了、谁这个月的模型开销、哪个后台任务在失败。

**它没有让上面那句"技术上:全部"变得更宽** —— 有 root 的人本来就看得到这些。
变的是另一头:**运营台上每一次跨用户的读取都会写一行审计日志**,
记的是"什么时候、看了谁的哪一类数据"。

日志在白杨自己的服务器上,他能删掉它 —— 所以这不是一道保障,
是一道**痕迹**。它和上面那句话不矛盾:能看到仍然是能看到,
而"顺手看一眼"从此不再是零成本的。

## 5. 你能自己做什么

**不需要找白杨帮忙的:**

| 想做什么 | 怎么做 |
| --- | --- |
| 停止采集 | App → 状态页 → 关掉采集。**服务端立刻吊销采集密钥并停掉白名单**,不等 App 配合 |
| 删掉已采的数据 | App → 状态页 → 删除采集数据。可以只删最近某一段 |
| 少采一点 | App → 白名单,逐条关掉不想采的 App |
| **关掉副驾** | App → 副驾 → 关掉。**或者直接收回系统的无障碍权限** —— 那一步不需要 App 配合,系统层面就断了 |
| **让副驾少看一点** | App → 副驾 → 逐个关掉不想让它读的聊天 App |
| **删掉副驾的聊天历史** | App → 副驾 → 清空历史。它只在你手机上,删了就没了 |
| 看它记住了什么 | App → 记忆页。每条都带出处,不认可的可以否定或改 |
| 在电脑上做上面这些 | App → 状态页 → 「在浏览器打开」。**那条链接不需要登录、十五分钟后失效**,里面能导出、能删、能加设备、能改白名单 |

**副驾那三行不需要找白杨,也不需要服务器配合。** 收回无障碍权限之后,
它在系统层面就读不到任何东西了 —— 这一条比其他几项都硬,
因为它不依赖这个系统的代码做对什么事。

**删除是真删。** 不留"以防万一"的副本。

跟着一起走的是**从那些通知派生出来的一切**:

| 删掉 | 为什么它必须跟着走 |
| --- | --- |
| 通知原文(`raw_events`) | 就是它本身 |
| 账目、待确认 | 直接指向那条通知 |
| 出处**只剩**这些事件的记忆条目 | 留着的话它们看起来仍然有出处,点开才发现没了 —— 那比留着原文更糟,它让"有出处"这件事变得不可信 |
| 出处只剩这些事件的待办与日程 | 同上。一条日程说"来自某条通知",而那条通知已经不在了 |
| 上面这些东西的**向量**(`embeddings`) | 向量是原文的有损编码。"删了但向量还在"不算删掉 |
| 别名上指向这些事件的**证据 id** | 证据没了就不该还写着;证据被清空的别名整条删掉 |

**出处不止这些事件的那些留着。** 一条"他不吃香菜"如果同时来自一封邮件和
一条通知,删掉通知之后它还有出处 —— 删了反而是删掉了邮件那一半。

### 有两样东西会留下,而这是有意的

- **审计记录**(`tool_calls`):"这个系统什么时候把什么发给了外部模型"。
  里面**没有内容,只有字段名和长度** —— 而删掉它等于让"它到底把什么发出去了"
  这个问题永远没法回答。这是保护你的记录,不是关于你的记录
- **推送记录**(`push_log`):同样只有标题和正文长度,没有正文。
  它是"误报率"这个数字唯一的来源,而那个数字决定要不要继续给你推东西

两样都不含通知原文。要连它们一起清掉,只能整个注销账户(下面那条)。

**要找白杨的:** 彻底注销账户、导出全部数据的归档文件。

## 6. 有些事这个系统做不到

诚实地列出来,免得你以为它能:

- **删不掉已经发出去的东西。** 推给你的消息、代你发出去的消息,
  发出去就在对方那里了
- **删不掉外部模型那边的记录。** 送出去的内容归那家公司的政策管
- **删不掉备份里的历史副本**,直到那份备份自己过期
- **挡不住有服务器权限的人。** 见第 4 节

### 副驾还有三条,必须单独说

- **它的判断会错。** 危险等级、"对方想要什么"这些都是模型猜的,不是事实。
  **它猜错的时候看起来和猜对一模一样** —— 屏幕上都是一个笃定的结论加一个百分比
- **候选回复可能被对方带偏。** 如果对方故意在消息里写一些话来影响它,
  起草出来的候选是可能被影响的。所以**填进输入框之后请自己看一眼再发** ——
  面板会自动收起来,就是为了让你能看见输入框里躺着什么
- **微信可能因为副驾限制你的账号。** 这件事今天没有发生过,
  微信目前的做法是"让它读不到"而不是封号。**但这是别人的规则,不是承诺** ——
  用副驾就是在承担这个风险,而承担的是你的账号。
  不想承担就别开它,日程、账单、记忆都不依赖它

## 7. 出了事怎么办

- **想停下来**:App 里关掉采集。这一步不需要通知任何人,也不需要理由
- **发现不对劲**(收到不该收到的推送、看到不属于你的数据):
  立刻告诉白杨,并在 App 里关掉采集
- **想退出**:关掉采集 + 删除数据,然后告诉白杨注销账户

## 8. 这份说明什么时候会变

采集的来源、送给模型的字段、数据的保留期 —— 这三样里任何一样变了,
**这份文档要先改,而且要主动告诉你**,不是等你自己发现。

改了不告诉,和一开始就没说清楚是一回事。

### 改过的地方

- **2026-09-22 · 副驾。** 采集来源多了一条(当前聊天窗的对话),
  送给模型的内容多了一条(那段对话)。**这是一次需要主动告知的变更** ——
  按上面那条规矩,这份文档在代码动工之前先改了。
  副驾默认关闭,不开它的话上面这两条与你无关
