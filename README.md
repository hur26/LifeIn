## 一分钟理解这个项目

**它是什么**:一个跑在你自己服务器上的程序。它定时去读你的邮箱、日历、账单和笔记,
把散落各处的生活信息整理成结构化记忆,然后通过企业微信给你推送摘要和提醒。
你也可以直接在企业微信里问它问题、让它干活。

**它不是什么**:不是通用 agent 框架,不是给陌生人用的商业产品,不是聊天机器人。

**核心设计约束**:

1. **数据整合比 agent 编排重要。** 把邮件、日历、账单、笔记归一成统一的生活事件流是脏活,
   没有技术含量,但没有它上层全是空的。
2. **长期记忆是唯一的护城河。** 生活助手的价值几乎全部来自"它记得你"。
3. **能动手的地方必须能刹车。** 一切写外部世界的操作走审批队列,可回滚,有审计。
4. **每一期都要能真的用起来。** 不接受"先搭三个月基础设施"。

## 技术栈(P0)

```
Python + FastAPI          接企业微信回调
APScheduler               定时调度
PostgreSQL (+ pgvector)   结构化数据 + 记忆向量,单库搞定
Claude API                直调,P0 不套 agent 框架
企业微信自建应用            推送 + 交互卡片
```

刻意**没有**引入 LangGraph / MCP / hook 机制 / 多 agent —— 理由见
[04 技术决策](docs/04-tech-decisions.md),每一条都写明了重新引入的触发条件。
